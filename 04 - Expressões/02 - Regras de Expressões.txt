Precedência de Operadores
Define a ordem em que as operações devem ser executadas em uma expressão, priorizando as de maior 
precedência.

Ordem de Operações (PEMDAS)
1. Parênteses: expressões dentro de símbolos de agrupamento.
2. Expoentes: potências e raízes.
3. Multiplicação e Divisão: avaliadas da esquerda para a direita.
4. Adição e Subtração: avaliadas da esquerda para a direita.

Nota
Multiplicação e divisão compartilham o mesmo nível de precedência, assim como adição e subtração.

Exemplos
x = (2² + 4) ∙ 3 - 6 / 2
x = 8 ∙ 3 - 3
x = 24 - 3
x = 21

Regras de Sinais
Regras que determinam como números positivos e negativos interagem nas operações aritméticas.

Multiplicação e Divisão
Sinais iguais produzem resultado positivo; sinais diferentes produzem resultado negativo (válido também para divisão).

+ ∙ + = +  
+ ∙ - = -  
- ∙ + = -  
- ∙ - = +

Adição e Subtração
Somar um número negativo equivale a subtrair seu valor absoluto; subtrair um negativo equivale a 
somar.

a + (-b) = a - b
a - (-b) = a + b

----------------------------------------------------------------------------------------------------

Valor Absoluto (Módulo)
A distância de um número até o zero na reta numérica, independentemente da direção. É sempre um 
valor não negativo.

|a| = a, se a ≥ 0
|a| = -a, se a < 0

Propriedades
- Não negativo: |a| ≥ 0 para todo a.
- Identidade: |a| = 0 se e somente se a = 0.
- Simetria: |a| = |-a| (números opostos possuem o mesmo módulo).
- Multiplicativo: |a ∙ b| = |a| ∙ |b|.
- Desigualdade triangular: |a + b| ≤ |a| + |b|.

Exemplos
|5| = 5,  |-5| = 5,  |-3 + 1| = |-2| = 2

Parênteses e Símbolos de Agrupamento
Símbolos usados para indicar que a expressão interna deve ser avaliada primeiro, sobrepondo a precedência padrão.

(2 + 3) ∙ 4 = 5 ∙ 4 = 20

Tipos de Símbolos
- Parênteses (): símbolo padrão de agrupamento em álgebra.
- Barra de fração: o numerador e o denominador são implicitamente agrupados.
- Símbolo radical: a expressão sob o radical é implicitamente agrupada.

Agrupamento Aninhado
Avalia-se primeiro a expressão mais interna, avançando para fora.

x = 3 ∙ (2 + (4 - 1))
x = 3 ∙ (2 + 3)
x = 3 ∙ 5
x = 15

Nota
Colchetes ([]) e chaves ({}) também são válidos para expressões aninhadas, mas parênteses são 
preferidos em álgebra.

Avaliação de Expressões
Processo de substituir as variáveis de uma expressão por valores dados e computar o resultado final.

Dada a expressão:
y = 2x² - 5x + 1,  para x = 3

Cálculo:
y = 2(3)² - 5(3) + 1
y = 2(9) - 15 + 1
y = 18 - 15 + 1
y = 4

Procedimento
1. Substituição: substituir cada variável pelo seu valor numérico, usando parênteses para evitar 
   erros de sinal.
2. Simplificação: aplicar a ordem de operações para computar o resultado.
