Adição
Operação aritmética básica que combina duas ou mais quantidades em um único valor chamado soma.

a + b = c

Propriedades
- Comutativa: a ordem dos operandos não altera o resultado, a + b = b + a.
- Associativa: o agrupamento dos operandos não altera o resultado, (a + b) + c = a + (b + c).
- Elemento neutro: somar 0 a qualquer número não altera seu valor, a + 0 = a.
- Elemento inverso (oposto): a soma de um número com seu oposto resulta em 0, a + (-a) = 0.

Exemplos
3 + 2 = 5,  -4 + 7 = 3,  10 + (-6) = 4

Subtração
Operação aritmética que calcula a diferença entre dois números, representando a remoção de uma 
quantidade de outra.

a - b = c

Propriedades
- Não comutativa: a ordem dos operandos altera o resultado, a - b ≠ b - a.
- Não associativa: o agrupamento dos operandos altera o resultado, (a - b) - c ≠ a - (b - c).
- Elemento neutro à direita: subtrair 0 de qualquer número não altera seu valor, a - 0 = a.
- Relação com a adição: subtrair é equivalente a somar o oposto, a - b = a + (-b).

Exemplos
7 - 3 = 4,  2 - 8 = -6,  -5 - (-3) = -2

----------------------------------------------------------------------------------------------------

Multiplicação
Operação aritmética que calcula o produto de dois números, representando a adição repetida de uma 
quantidade.

a ∙ b = c,  ab = c

Propriedades
- Comutativa: a ordem dos fatores não altera o produto, a ∙ b = b ∙ a.
- Associativa: o agrupamento dos fatores não altera o produto, (a ∙ b) ∙ c = a ∙ (b ∙ c).
- Distributiva em relação à adição: a ∙ (b + c) = a ∙ b + a ∙ c.
- Elemento neutro: multiplicar qualquer número por 1 não altera seu valor, a ∙ 1 = a.
- Propriedade do zero: multiplicar qualquer número por 0 resulta em 0, a ∙ 0 = 0.

Exemplos
3 ∙ 4 = 12,  -2 ∙ 5 = -10,  6 ∙ (-3) = -18,  ab = a ∙ b

Nota
Em álgebra, o ponto (∙) é a notação convencional. O símbolo × é válido, mas menos comum. Entre 
variáveis, o ponto pode ser omitido (ab = a ∙ b).

Divisão
Operação aritmética que calcula o quociente entre dois números, representando a divisão de uma 
quantidade em partes iguais.

a/b = c,  b ≠ 0

Propriedades
- Não comutativa: a ordem dos operandos altera o resultado, a/b ≠ b/a.
- Não associativa: o agrupamento dos operandos altera o resultado, (a/b)/c ≠ a/(b/c).
- Elemento neutro à direita: dividir qualquer número por 1 não altera seu valor, a/1 = a.
- Inversa da multiplicação: (a ∙ b) / b = a.
- Divisão por zero é indefinida: a/0 não possui valor definido para nenhum a.

Exemplos
12/4 = 3,  -10/2 = -5,  7/1 = 7

Nota
Em álgebra, a notação de fração a/b é a forma convencional. O símbolo obelo (÷) é válido, mas 
raramente usado em contextos algébricos.
