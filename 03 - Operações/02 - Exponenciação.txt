Exponenciação
Forma compacta de expressar a multiplicação repetida de um número por ele mesmo.

aⁿ = a ∙ a ∙ a ... a  (n fatores), n ∈ ℕ

Terminologia
- Base (a): o número multiplicando a si mesmo.
- Expoente (n): a quantidade de vezes que a base é multiplicada.
- Potência: o valor resultante da operação.
- Quadrado: resultado de elevar um número à potência 2 (a²).
- Cubo: resultado de elevar um número à potência 3 (a³).

Exemplos
2³ = 2 ∙ 2 ∙ 2 = 8,   5² = 5 ∙ 5 = 25,   10⁴ = 10 ∙ 10 ∙ 10 ∙ 10 = 10000

----------------------------------------------------------------------------------------------------

Leis dos Expoentes
Regras para simplificar e manipular expressões com potências com base real não nula.

aⁿ ∙ aᵐ   =  aⁿ⁺ᵐ
aⁿ / aᵐ   =  aⁿ⁻ᵐ,  a ≠ 0
(aⁿ)ᵐ     =  aⁿ˙ᵐ
(a ∙ b)ⁿ  =  aⁿ ∙ bⁿ
(a / b)ⁿ  =  aⁿ / bⁿ,  b ≠ 0

----------------------------------------------------------------------------------------------------

Valores Especiais de Expoente
Casos particulares decorrentes das leis dos expoentes.

Base Zero:       0ⁿ  =  0,  n > 0
Expoente Zero:   a⁰  =  1,  a ≠ 0
Base Um:         1ⁿ  =  1
Expoente Um:     a¹  =  a
Base Negativa:  -aⁿ  =  -(aⁿ)
Expoente Neg.:   a⁻ⁿ =  1 / aⁿ,  a ≠ 0

Base e Expoente Zero
Indefinido/indeterminado na maioria dos contextos matemáticos devido a contradições formais.

0⁰ = indefinido

Expoentes Fracionários
Um expoente fracionário representa uma radiciação: o denominador é o índice da raiz e o numerador é 
o expoente da base.

aᵐ/ⁿ = ⁿ√(aᵐ),  a ≥ 0
