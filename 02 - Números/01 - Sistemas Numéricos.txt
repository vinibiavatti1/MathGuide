Números Naturais
ℕ = {0, 1, 2, 3, 4, 5, ...}

Propriedades
- Infinito: não existe maior número natural.
- Discreto: não há números naturais entre dois consecutivos (ex.: entre 1 e 2).
- Fechado sob adição e multiplicação: operar dois naturais com adição ou multiplicação sempre 
  resulta em um número natural.
- Não fechado sob subtração e divisão: a operação pode resultar em um número fora de ℕ (ex: 2 − 5 
  ou 1 / 3).

Exemplos
0, 1, 2, 3, 42, 1000

Nota
Algumas definições excluem o 0.

----------------------------------------------------------------------------------------------------

Números Inteiros
ℤ = {..., -3, -2, -1, 0, 1, 2, 3, ...}

Propriedades
- Infinito em ambas as direções: não há maior nem menor inteiro.
- Discreto: não há inteiros entre dois consecutivos.
- Fechado sob adição, subtração e multiplicação: as operações entre inteiros sempre geram um inteiro.
- Não fechado sob divisão: pode gerar frações (ex.: 1 / 3).
- Relação: todo natural é inteiro (ℕ ⊂ ℤ).

Exemplos
..., -3, -2, -1, 0, 1, 2, 3, ...

Nota
O símbolo ℤ vem do alemão "Zahlen" (números).

----------------------------------------------------------------------------------------------------

Números Racionais
ℚ = {p/q ∣ p ∈ ℤ, q ∈ ℤ, q ≠ 0}

Propriedades
- Fechado sob as 4 operações básicas: adição, subtração, multiplicação e divisão (exceto por zero) 
  sempre geram um racional.
- Denso: sempre existe outro número racional entre dois racionais quaisquer.
- Relação: todo inteiro é racional (ℤ ⊂ ℚ, pois n = n/1).

Exemplos
1/2, 3/4, -5/3, 0.333...

Nota
O símbolo ℚ vem de "quociente".

----------------------------------------------------------------------------------------------------

Números Irracionais
ℝ \ ℚ = {x ∣ x ∈ ℝ, x ∉ ℚ}

Propriedades
- Não periódico e infinito: representação decimal infinita sem padrão de repetição.
- Irredutível a fração: não podem ser expressos como a razão de dois inteiros.
- Denso: sempre existe um irracional entre dois números reais quaisquer.
- Relação: são subconjuntos dos reais (ℝ \ ℚ ⊂ ℝ).

Exemplos
√2, π, e, √3, ...

Nota
Não possuem símbolo dedicado único (usa-se ℝ \ ℚ ou 𝕀).

----------------------------------------------------------------------------------------------------

Números Reais
ℝ = ℚ ∪ (ℝ \ ℚ)

Propriedades
- Contínuo (Completo): não há "buracos" na reta numérica; cada ponto corresponde a um real.
- Denso: sempre existe outro número real entre dois reais quaisquer.
- Fechado sob as operações básicas (exceto divisão por zero).
- Relação: engloba racionais e irracionais (ℚ ⊂ ℝ e ℝ \ ℚ ⊂ ℝ).

Exemplos
-3, 1/2, √2, π, 0.333...

----------------------------------------------------------------------------------------------------

Números Imaginários
i = √-1

Forma Geral
bi, b ∈ ℝ

Propriedades
- Não reais: não pertencem à reta dos números reais.
- Ciclo de potências: as potências de i repetem em ciclos de 4 (i¹ = i, i² = -1, i³ = -i, i⁴ = 1).
- Fechado sob adição e multiplicação (gerando resultados imaginários ou reais).

Exemplos
√-1 = i,  √-4 = 2i,  √-9 = 3i

----------------------------------------------------------------------------------------------------

Números Complexos
ℂ = {z = a + bi ∣ a ∈ ℝ, b ∈ ℝ}

Notação
z ∈ ℂ, Re(z) = a, Im(z) = b (parte real e parte imaginária)

Propriedades
- Completo: sistema numérico máximo que engloba todos os anteriores.
- Fechado sob as 4 operações básicas (exceto divisão por zero).
- Relação: todo real e todo imaginário é um número complexo (ℝ ⊂ ℂ e i ∈ ℂ).

Exemplos
3+2i,  -1+5i,  4+0i,  0+3i

Nota
Se b = 0, reduz-se a real. Se a = 0, reduz-se a imaginário puro.

----------------------------------------------------------------------------------------------------

Inclusão de Conjuntos Numéricos
Hierarquia de conjuntos aninhados:

ℕ ⊂ ℤ ⊂ ℚ ⊂ ℝ ⊂ ℂ

Propriedades
- Cada conjunto estende o anterior adicionando novos elementos (negativos, frações, irracionais, 
  imaginários).
- Todo elemento de um conjunto menor pertence automaticamente a todos os conjuntos maiores à sua 
  direita.

Exemplo
O número 3 em cada nível da hierarquia:

3 ∈ ℕ,  3 ∈ ℤ,  3 = 3/1 ∈ ℚ,  3 ∈ ℝ,  3 = 3+0i ∈ ℂ
